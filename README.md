# MC Manager

A desktop application for managing Minecraft Java Edition files, built with Java and JavaFX.

MC Manager provides a graphical interface for browsing and managing worlds, resource packs and shader packs.

## Features

### General
- Graphical interface built with JavaFX
- Multiple language support *(WIP - option to switch languages not implemented)*
- Light and dark themes *(WIP - currently only base theme available)*

### World Management
- Browse Minecraft worlds
- View world information such as game mode, difficulty, version, and seed
- Search and sort worlds
- Open world folders
- Delete worlds

### Resource Pack Management
- Browse installed resource packs
- View pack icons and descriptions
- Support ZIP and folder-based packs

### Shader Pack Management
- Browse installed shader packs
- Support ZIP and folder-based packs

## Planned Features

- **Mod support** — Browse and manage installed Minecraft mods.
- **Modpack management** — Create and manage custom modpacks.
- **World backups** — Create, restore, and manage backups of Minecraft worlds.
- **Settings and customization** — Add a dedicated settings menu for:
  - Themes and appearance
  - Minecraft file and directory locations
  - Application language
  - Date and time formatting preferences
- **Possible future feature: Minecraft launcher** — Launch Minecraft directly from the application, potentially with selectable game versions and custom launch arguments.

## Technologies

- **Java** — Application logic
- **JavaFX** — User interface
- **FXML & CSS** — UI layout and styling
- **SLF4J** — Logging
- **Querz NBT** — Reading Minecraft world data
- **Gson** — Reading resource pack metadata
- **Apache Commons IO** — File operations
